El presente proyecto tiene como propósito principal poner en práctica los conocimientos fundamentales sobre la gestión y manipulación de bases de datos relacionales utilizando Microsoft SQL Server y la herramienta SQL Server Management Studio (SSMS). Utilizando como caso de estudio la base de datos comercial "Northwind", se busca simular escenarios reales de administración y extracción de datos.

A lo largo del documento, se expone el proceso completo de configuración del entorno de trabajo, seguido por la resolución de una serie de ejercicios prácticos divididos en dos grandes enfoques. Por un lado, se aborda la creación de Vistas (Views) para optimizar y estructurar las consultas de información, lo que facilita enormemente la lectura de métricas y cruces de datos provenientes de múltiples tablas. Por otro lado, se implementan Procedimientos Almacenados (Stored Procedures), los cuales permiten automatizar tareas operativas mediante la integración de lógica de programación escalable, condiciones de búsqueda y parámetros de validación para asegurar la integridad de las transacciones sin generar errores en el sistema.

En conjunto, esta práctica sirve como evidencia del aprendizaje y dominio en el manejo del lenguaje SQL, demostrando la capacidad de interactuar con éxito con un sistema gestor de bases de datos robusto para transformar datos crudos en información útil y estructurada.
