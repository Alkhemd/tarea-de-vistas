# Reglas para la Actividad de Respaldos y SQL Agent

A peticion del usuario, se establecen las siguientes 5 reglas estrictas para la redaccion y formato de los documentos dentro de esta carpeta (`pag 6 a la 29`):

1. **Estilo de Redaccion:** La redaccion ya no se realizara en primera persona ("yo hice", "cree"). A partir de ahora, todo el texto debera redactarse de **manera general e impersonal** (por ejemplo: "Se realiza la creacion...", "Se procede a...", "Se escribe el comando...").
2. **Documentacion Paso a Paso:** La redaccion en el archivo `actividad_1_respaldos.md` se construira guiandose **estricta y unicamente** paso a paso de acuerdo a las imagenes proporcionadas por el usuario. 
3. **Espacios para Capturas de Pantalla:** Debajo de la redaccion que explica cada paso iterativo, se debera colocar explicitamente un espacio o marcador destinado para las capturas de pantalla que el usuario ira recopilando a lo largo de la actividad (ej. `[ESPACIO PARA CAPTURA AQUI]`).
4. **Cero Inventivas (Regla de Oro):** No se deben realizar acciones, suposiciones, ni inventar pasos o codigos que no hayan sido explicitamente solicitados por el usuario o mostrados en sus evidencias. Todo avance requiere permiso o directriz directa.
5. **Cero Caracteres Especiales:** En el documento final (`actividad_1_respaldos.md`) queda estrictamente prohibido el uso de caracteres especiales de formateo Markdown como asteriscos (`*`) o numerales (`#`). El texto entregado debe ser completamente limpio y plano a peticion del usuario.
